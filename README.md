# B8 · Plataforma de Antecipação · Demo

Protótipo navegável da plataforma proprietária de antecipação de recebíveis para o B8.

🔗 **Demo:** https://gustavogm9.github.io/rafael-b8/
🔑 **Acesso:** restrito por senha (enviada pelo Gustavo · Guilds)

---

**Sobre**

Demo de alta fidelidade da plataforma SaaS de antecipação para o B8, cobrindo:

- Portal do cedente (upload de NF/XML, meus títulos, carteira financeira, Mini CRM, agenda, documentos)
- Backoffice do analista (esteira multi-filial, drawer de aprovação, audit log)
- Painel do gestor + Workflow de aprovações pendentes
- Operações: substituição, prorrogação, recompra
- Galeria mobile (PWA responsivo)

Protótipo cliente-side encriptado com AES-256 (StaticCrypt) · sem backend exposto.
